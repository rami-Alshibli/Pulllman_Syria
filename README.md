# 🚌 GoBus - منصة حجز وإدارة تذاكر البولمان الذكية

منصة متكاملة لإدارة وحجز تذاكر الحافلات والبولمانات بين المدن السورية، تتألف من **خادم خلفي (Backend)**، و**لوحة تحكم وإدارة ويب (Web Dashboard)**، و**تطبيق هواتف ذكية (Mobile App)**.

---

## 🌟 المكونات الأساسية للنظام

### 1. ⚙️ الخادم الخلفي (Backend Service)
- **المسار:** `Bus_Reservation/`
- **التقنيات المستخدمة:** NestJS, TypeScript, MongoDB (Mongoose), JWT, bcrypt.
- **المنفذ الافتراضي:** `3000`
- **المميزات:**
  - إدارة المستخدمين والصلاحيات (Admin, Secretary, Customer).
  - إدارة المحطات والرحلات ونماذج الحافلات (Bus Models).
  - معالجة الحجوزات، التحقق من السعة والمقاعد الشاغرة، وتثبيت الدفع.

### 2. 💻 لوحة تحكم الويب (Web Dashboard)
- **المسار:** `frontend_web/client/`
- **التقنيات المستخدمة:** Next.js 14 (App Router), React, Tailwind CSS, Lucide Icons.
- **المنفذ الافتراضي:** `3001`
- **المميزات:**
  - بوابة تسجيل الدخول الموحدة للمدراء وموظفي السكرتاريا.
  - **لوحة المدير (`/admin`):** إدارة الأساطيل، الرحلات، الأسعار، والمحطات.
  - **لوحة السكرتاريا (`/secretary`):** إدارة وتثبيت الحجوزات النقدية وخريطة المقاعد التفاعلية (32 مقعداً).

### 3. 📱 تطبيق الموبايل (Mobile Application)
- **المسار:** `mobile_app/`
- **التقنيات المستخدمة:** React Native, Expo, Expo Router, NativeWind.
- **المنفذ الافتراضي:** `8081` (Expo Metro)
- **المميزات:**
  - استعراض الرحلات المتاحة ومواعيدها وأسعارها.
  - خريطة مقاعد تفاعلية مطابقة تماماً للويب (8 صفوف × 4 مقاعد = 32 مقعداً) مع تمييز دقيق للمقاعد المتاحة، المحجوزة، والمثبتة نقداً.
  - إمكانية الحجز الفوري وإدارة الحجوزات السابقة.

## 🚀 التشغيل السريع (1-Click Launchers)

تم تجهيز ملفات تشغيل سريعة بضغطة زر واحدة لتسهيل العرض والتسليم:

| الملف | الوظيفة |
| :--- | :--- |
| **`START_PROJECT.bat`** | يشغّل MongoDB، سيرفر الباك ايند، لوحة الويب، وتطبيق الموبايل دفعة واحدة. |
| **`START_MOBILE.bat`** | يكتشف عنوان الـ Wi-Fi تلقائياً ويشغّل تطبيق الموبايل مع إظهار رمز QR للفتح عبر Expo Go. |
| **`RUN_ON_ANDROID_EMULATOR.bat`** | يشغّل محاكي أندرويد ستوديو (`Pixel_10_Pro`) مع توجيه المنافذ وفتح التطبيق عليه تلقائياً. |
