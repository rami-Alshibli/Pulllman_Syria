## 2. الروابط والمنافذ (Ports)

- **خادم الباك ايند (NestJS Backend API)**: [http://localhost:3000](http://localhost:3000)
- **قاعدة البيانات (MongoDB)**: `mongodb://localhost/nest` (منفذ 27017)

## 3. طريقة التشغيل السريع

### تشغيل النظام بالكامل (الباك ايند + لوحة التحكم الويب):
انقر نقراً مزدوجاً على الملف:
```cmd
START_PROJECT.bat
```
يقوم هذا السكربت تلقائياً بـ:
1. فحص MongoDB وتشغيله تلقائياً.
2. تغذية قاعدة البيانات بالبيانات الافتراضية.
3. استكشاف آي بي الواي فاي وتحديث `.env` لتطبيق الموبايل.
4. تشغيل الباك ايند (NestJS) على منفذ 3000.
5. تشغيل لوحة التحكم الويب (Next.js) على منفذ 3001.

### تشغيل تطبيق الموبايل (Expo):
- **لتشغيل تطبيق الموبايل على الهاتف عبر Expo Go**:
  شغّل الملف: **`START_MOBILE.bat`**
  وامسح الرمز (QR Code) بكاميرا الهاتف أو تطبيق **Expo Go**.
- **لتشغيل تطبيق الموبايل على المتصفح مباشرة**:
  شغّل الملف: `START_MOBILE_WEB.bat`

## 4. ما تم إنجازه في النسخة الجديدة لتطبيق الموبايل (`mobile_app`)

1. **تثبيت حزم الاعتماديات**:
   - تثبيت كافة الحزم والاعتماديات بنجاح (`879 packages installed`).
2. **ضبط وإصلاح الاتصال بالباك ايند (`apis.ts`)**:
   - تفعيل التعرف التلقائي على عنوان الآي بي للجهاز عبر `expo-constants` وعبر `.env` لمنع خطأ `Failed to connect to localhost/127.0.0.1`.
   - توجيه نقاط النهاية إلى الصيغة المفردة المعتمدة في الباك ايند (`/trip` و `/booking`).
   - استخراج وتسطيح كائنات Mongoose (`_doc`) لضمان ظهور تفاصيل الرحلات والمقاعد بسلاسة.
   - حل مشكلة شرط الأمان في الباك ايند للاستعراض السريع للرحلات دون اشتراط تسجيل مسبق قبل اختيار الرحلة.
3. **التوافق التام مع TypeScript**:
   - استبعاد مجلدات الأمثلة غير المستخدمة `example` وإصلاح توافق خصائص `TripCard`.
   - اجتياز `npx tsc --noEmit` بنتيجة **0 أخطاء**.
4. **نجاح فحص البناء والتصدير**:
   - اجتياز `npx expo export -p web` بنجاح كامل (**Code 0**).
5. **سلامة الباك ايند**:
   - شجرة العمل في مجلد الباك ايند `Bus_Reservation` نظيفة تماماً 100% (**Working tree clean**).
